# The website

A static site in six languages for Cloudflare Pages. No JavaScript, no cookies, nothing loaded from other
origins; the CSP in `_headers` enforces that.

```sh
python3 site/tools/build.py        # builds site/dist
python3 site/tools/check.py        # checks the build: links, hreflang, titles, JSON-LD, leftover {{tags}}
python3 -m http.server -d site/dist 8000
```

## Changing the name

The app's name is `name` in `site.json`. Every page, title, alt text, the JSON-LD, `llms.txt` and the sitemap
read it from there. The social card (`img/og-card.png`) deliberately has no name on it. After renaming, rebuild.
`origin` is the site's address and `cloudflare_project` the Pages project; change them when the real domain is known.

## Files

```
site.json            name, address, version, download links; "placeholders" marks links that aren't real yet
cameras.json         the supported-camera list, shared by every language
i18n/<lang>.json     every string; {name} and {version} are filled in at build time
templates/*.html     base.html wraps home, cameras, privacy and 404
css/site.css         the one stylesheet, edited by hand; build.py inlines it into every page
img/                 generated by tools/assets.sh (screenshots also as WebP), committed; pages link them with ?v=<hash>
_headers, _redirects Cloudflare Pages
tools/build.py       templates + i18n -> dist/, sitemap.xml, robots.txt, llms.txt, llms-full.txt
tools/check.py       checks dist/
tools/assets.sh      screenshots and the social card (icons: brand/export.sh)
tools/mockups/       sources for the images: sample photos, a drawing of the Mac app, the social card
```

Adding a language: add its code to `languages` in `site.json` and an `i18n/<code>.json` with the same keys as
`en.json` (the build fails if any are missing).

## Download links

While a release isn't out, the links point to the GitHub releases page and are listed in `placeholders`, which
shows a "coming soon" label and tells `llms.txt` they aren't released yet. When a download is real, put its URL
in `downloads` and remove its key from `placeholders`.

## Screenshots

`tools/assets.sh` regenerates `img/`:

- `screenshot-desktop.png` is the real Windows/Linux UI (`apps/desktop`), built with the Tauri APIs replaced by
  `tools/mockups/desktop/tauri-mock.ts`, which feeds it sample photos.
- `screenshot-mac.png` is a drawing of the Mac app (`tools/mockups/mac.html`) until there's a real screenshot.
  To use a real one, take it with ⌘⇧4 then Space on the app window, and run
  `MAC_SCREENSHOT=~/Desktop/shot.png site/tools/assets.sh`.

The sample photos are drawn by `tools/mockups/scenes.py`, so no one's real photos end up on the site.

## Deploying

Cloudflare Pages, connected to this repository:

- Build command: `python3 site/tools/build.py`
- Build output directory: `site/dist`
- Root directory: `/` (the default)

Or from a machine with Wrangler: `npx wrangler pages deploy site/dist --project-name <cloudflare_project>`.
The `site` workflow builds and checks the site on every change and deploys it when the `CLOUDFLARE_API_TOKEN`
and `CLOUDFLARE_ACCOUNT_ID` secrets are set.
